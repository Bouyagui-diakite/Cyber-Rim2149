# Cyber-Rim 2149

Boutique en ligne de jeux vidéo et de matériel gaming pour la Mauritanie, avec une identité visuelle cyberpunk.

## Fonctionnalités

- Catalogue de jeux et de matériel, avec recherche et filtres par catégorie
- Fiches produits détaillées
- Panier, tunnel de commande et espace client
- Interface animée (transitions de pages, apparitions au défilement)
- Trilingue : français, anglais, arabe (RTL)

## Stack

React 18 · Vite · Material UI · Framer Motion · React Router · i18next

## Démarrage

```bash
npm install
npm run dev
```
